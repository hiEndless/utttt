# RSI + MACD 组合指标解读

## 指标列表

| 组合名称                                | 说明      |
| ----------------------------------- | ------- |
| ① RSI 反弹 + MACD DIF 上穿 DEA（经典反转）    | 最基本反转信号 |
| ② RSI 超卖 <30 + MACD 零轴以下 DIF/DEA 金叉 | 底部反转    |
| ③ RSI 超买 >70 + MACD 零轴以上 DIF/DEA 死叉 | 顶部反转    |
| ④ RSI 背离 + MACD 金叉确认                | 强化的反转信号 |
| ⑤ RSI 背离 + MACD 柱子翻红                | 动能确认    |
| ⑥ RSI 趋势上破 50 + MACD 上穿 0 轴         | 趋势反转确认  |
| ⑦ RSI 从 50 下破 + MACD 下破 0 轴         | 熊趋势确认   |
| ⑧ RSI 回踩 40–50 反弹 + MACD DIF>DEA    | 顺趋势反弹做多 |
| ⑨ RSI 回抽 50–60 受阻 + MACD DIF<DEA    | 顺趋势回撤做空 |
| ⑩ RSI 超卖区金叉形态 + MACD 柱子缩短（衰竭）       | 快速反转    |
| ⑪ RSI 超买区死叉形态 + MACD 柱子缩短（衰竭）       | 快速顶背反转  |
| ⑫ RSI 突破 70 强势区 + MACD 柱子放大         | 强动能突破   |

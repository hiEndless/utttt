# MACD + EMA 组合指标

## 指标解读

| 序号    | 组合信号名称                                    | 触发逻辑解释            | 强度    |
|-------| ----------------------------------------- | ----------------- | ----- |
| **1** | EMA 金叉 + MACD 柱翻正                         | 多头趋势+动能确认         | ⭐⭐⭐⭐⭐ |
| **2** | EMA 死叉 + MACD 柱翻负                         | 空头趋势+动能确认         | ⭐⭐⭐⭐⭐ |
| **3** | EMA 金叉 + MACD 顶背离（偏弱）                     | 趋势刚形成，但动能未跟随（需过滤） | ⭐⭐⭐   |
| **4** | EMA 死叉 + MACD 底背离（偏弱）                     | 空头趋势形成但动能减弱       | ⭐⭐⭐   |
| **5** | EMA 金叉 + MACD 0轴突破                        | DIF 由下向上穿越 0 轴    | ⭐⭐⭐⭐  |
| **6** | EMA 死叉 + MACD 0轴跌破                        | DIF 从 0 上方掉下      | ⭐⭐⭐⭐  |
| **7** | EMA 双金叉（ema5 > ema12 > ema26）+ DIF 金叉 DEA | 多头趋势强化的二次确认       | ⭐⭐⭐⭐⭐ |
| **8** | EMA 双死叉（ema5 < ema12 < ema26）+ DIF 死叉 DEA | 空头趋势强化二次确认        | ⭐⭐⭐⭐⭐ |
| **9** | EMA 金叉出现后，MACD 连续两根绿柱缩短（多头二次确认）           | 动能持续增强            | ⭐⭐⭐⭐  |
| **10** | EMA 死叉后，MACD 连续两根红柱缩短（空头二次确认）             | 空头衰竭+回调确认         | ⭐⭐⭐   |

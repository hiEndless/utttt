# BOLL + VOL  组合指标解读

## 指标列表
| 信号名称                  | 触发条件                | 技术解读                          | 操作建议                  | 强度   |
| --------------------- | ------------------- | ----------------------------- | --------------------- | ------ |
| **Breakout Up Vol**   | 收盘价突破上轨且成交量放大       | 市场处于强势上涨趋势，突破伴随成交量确认，趋势延续可能性大 | 可考虑顺势做多，设置止损在中轨或上轨回踩处 | ⭐⭐⭐⭐⭐ |
| **Breakout Down Vol** | 收盘价跌破下轨且成交量放大       | 强势下跌趋势确认，突破伴随成交量放大，趋势延续可能性大   | 可考虑顺势做空，止损设置在中轨或下轨回弹处 | ⭐⭐⭐⭐⭐ |
| **Midband Pullback**  | 收盘价回踩中轨且成交量缩小       | 调整回调至中轨支撑，市场仍处于震荡或上升趋势中       | 可考虑低位买入，止损略低于下轨       | ⭐⭐⭐   |
| **ATR Breakout Up**   | 带宽极窄，收盘价上涨幅度大于ATR   | 市场震荡后爆发向上突破，可能形成新一轮趋势         | 可做多突破方向，止损根据ATR设置     | ⭐⭐⭐⭐  |
| **ATR Breakout Down** | 带宽极窄，收盘价下跌幅度大于ATR   | 市场震荡后爆发向下突破，趋势可能持续            | 可做空突破方向，止损根据ATR设置     | ⭐⭐⭐⭐  |
| **Vol Spike**         | 成交量相比前一根K线放大 > 1.5倍 | 成交量异常放大，市场活跃度提高，可能伴随趋势启动或回调结束 | 可关注趋势方向，择机入场          | ⭐⭐⭐   |
| **Vol Drop**          | 成交量相比前一根K线缩小 < 0.5倍 | 成交量骤减，市场观望，趋势可能衰竭或盘整          | 可谨慎观望或考虑止盈平仓          | ⭐⭐    |

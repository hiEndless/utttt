# RSI + KDJ 组合指标解读

## 指标列表
| 组合名称                                 | 涉及指标                    | 触发条件                                                             | 信号意义                                |
| ------------------------------------ | ----------------------- | ---------------------------------------------------------------- | ----------------------------------- |
| **1. RSI 反弹 + KDJ 金叉（经典反转）**         | RSI14、K、D、K_prev、D_prev | - RSI14 从 <30 上穿 30 <br> - KDJ 金叉（K_prev ≤ D_prev 且 K > D）       | 短线超卖区反弹，趋势可能由空转多，捕捉底部起涨点            |
| **2. RSI 反弹 + KDJ 极值（J < 10）**       | RSI14、J                 | - RSI14 从 <30 上穿 30 <br> - J < 10（极端超卖）                          | 极端超卖反弹信号，通常用于大阴线后的低位反弹确认，风险较低但信号稍滞后 |
| **3. RSI 背离 + KDJ 超卖**               | RSI14、K、D、J、价格收盘价       | - 价格创新低 <br> - RSI14 未创新低（底背离） <br> - KDJ 低位徘徊（K、D、J 低于 20）      | 底部潜在反转信号，比普通反弹更强，暗示空头动能衰竭，可能启动上涨    |
| **4. 二次探底（RSI/KDJ）**                 | RSI14、K、J、前低价格          | - 前期低点反弹 <br> - 再次回踩但不破前低 <br> - RSI14 仍处低位 <br> - KDJ 仍处低位或出现金叉 | 底部确认信号，二次探底失败后通常伴随趋势启动              |
| **5. RSI 下穿 70 + KDJ 死叉（顶部反转）**      | RSI14、K、D、K_prev、D_prev | - RSI14 从 >70 下穿 70 <br> - KDJ 死叉（K_prev ≥ D_prev 且 K < D）       | 超买区域顶部反转信号，短线可能出现下跌                 |
| **6. RSI 顶背离 + KDJ 高位钝化**            | RSI14、K、D、J、价格收盘价       | - 价格创新高 <br> - RSI14 高点下降 <br> - K/D/J > 80                      | 顶部潜在反转信号，比单指标更可靠，适合波段顶判断            |
| **7. KDJ 高位三重顶 + RSI 回落**            | RSI14、K、D、J             | - KDJ 高位连续三次局部峰值 <br> - RSI14 同步回落                               | 高位震荡顶部信号，提示短线回调风险                   |
| **8. RSI >50 + KDJ 金叉（趋势确认）**        | RSI14、K、D、K_prev、D_prev | - RSI14 持续站稳 >50 <br> - KDJ 金叉                                   | 趋势启动信号，适合捕捉中期上涨趋势                   |
| **9. RSI 多头排列 + KDJ 中位上穿 50**        | RSI14、RSI6、K、D          | - RSI短期 > 长期（多头排列） <br> - KDJ 中位上穿 50                            | 趋势加速信号，确认上涨动力强                      |
| **10. RSI 区间震荡 + KDJ 反复金叉（箱体底部）**    | RSI14、K、D、J             | - RSI 在 30~60 区间反复 <br> - KDJ 低位多次金叉                             | 区间行情底部震荡反弹信号，短线多次低吸机会               |
| **11. RSI 区间 + KDJ 顶背离（箱体顶部）**       | RSI14、K、D、J、价格收盘价       | - RSI 40~70 区间 <br> - KDJ 高位出现背离                                 | 区间顶部反转信号，提示高抛机会                     |
| **12. RSI 假突破（>70 又回落） + KDJ 死叉**    | RSI14、K、D、K_prev、D_prev | - RSI14 突破 70 后快速下落 <br> - KDJ 高位死叉                              | 假突破顶部信号，短线回调风险高                     |
| **13. RSI 底部假跌破（<30 立刻收回） + KDJ 金叉** | RSI14、K、D、J             | - RSI14 <30 但快速回升 <br> - KDJ 金叉                                  | 底部假跌破后的强反弹信号，短线多头机会                 |
| **14. RSI 波峰/波谷节奏 + KDJ 波峰/波谷同步**    | RSI14、K、D、J             | - RSI 形成 M/W 顶底形态 <br> - KDJ 同步波峰波谷                              | 波段交易信号，确认节奏共振，适合 swing 操作           |
| **15. RSI 趋势线突破 + KDJ 位置确认**         | RSI14、K、D、J、趋势线         | - RSI 底部斜率线突破 <br> - KDJ 低位金叉                                    | 趋势启动信号，确认上涨动力和位置可靠性                 |

# BOLL + KDJ 组合指标解读

## 指标简介
| **信号名称**                            | **触发条件（逻辑）**                 | **技术解读**                    | **操作建议**          | **强度** |
| ----------------------------------- | ---------------------------- | --------------------------- | ----------------- | ------ |
| **低位反转（bullish low reversal）**      | J 从 <20 上穿 20 且 收盘站上 BOLL 中轨 | 超卖→反弹→趋势开始转强，三重反转确认         | 可尝试做多，止损放在中轨下方或下轨 | ⭐⭐⭐⭐  |
| **高位反转（bearish high reversal）**     | J 从 >80 下穿 80 且 收盘跌破中轨       | 超买→回落→趋势转弱的明显信号             | 可做空或止盈减仓，止损在中轨之上  | ⭐⭐⭐⭐  |
| **金叉 + 中轨支撑**                       | K 上穿 D（KDJ 金叉）且 收盘在中轨上方      | 动能转强 + 均线支撑 → 趋势向上延续        | 顺势做多，加仓信号         | ⭐⭐⭐⭐  |
| **死叉 + 中轨压制**                       | K 下穿 D（KDJ 死叉）且 收盘在中轨下方      | 动能转弱 + 中轨压制 → 下跌趋势可能延续      | 顺势做空或减仓风险品种       | ⭐⭐⭐⭐  |
| **极度超卖反弹（J < 10 + 下轨支撑）**           | J < 10 且 收盘价靠近/触碰下轨          | 超卖极值 + 下轨支撑 → 短线反弹机会        | 仅适合短线抄底，趋势行情中需谨慎  | ⭐⭐⭐   |
| **极度超买回落（J > 90 + 上轨遇阻）**           | J > 90 且 收盘价接近/触碰上轨          | 超买极值 + 上轨压力 → 易出现回调         | 高位止盈、短空机会         | ⭐⭐⭐   |
| **双重底反转（下轨附近金叉）**                   | 价格接近下轨 & KDJ 金叉              | BOLL 下轨支撑 + KDJ 反转 → 双底强化信号 | 比普通金叉更强，可小仓试多     | ⭐⭐⭐⭐  |
| **双重顶反转（上轨附近死叉）**                   | 价格接近上轨 & KDJ 死叉              | BOLL 上轨压力 + KDJ 死叉 → 强势顶部信号 | 高位空头形态，可轻仓试空或减仓   | ⭐⭐⭐⭐  |
| **KDJ 底背离 + 带宽收窄（bull divergence）** | BOLL 带宽极窄 & 价格创新低但 J 未创新低    | 动能减弱 + 市场压缩 → 大级别底部         | 中期反转先行信号，可逐步布局    | ⭐⭐⭐⭐⭐ |
| **KDJ 顶背离 + 带宽收窄（bear divergence）** | 带宽极窄 & 价格创新高但 J 未创新高         | 上涨乏力 + 收缩 → 大级别顶部风险         | 中期反转警示信号，逐步减仓     | ⭐⭐⭐⭐⭐ |
| **趋势确认上行**                          | K 上穿 50 且 收盘价在中轨上方           | 多头区间确立，上升趋势成熟               | 顺势做多，回踩中轨可加仓      | ⭐⭐⭐⭐  |
| **趋势确认下行**                          | K 下穿 50 且 收盘价在中轨下方           | 空头区间确立，下跌趋势增强               | 顺势做空，反弹至中轨可加仓     | ⭐⭐⭐⭐  |

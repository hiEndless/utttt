# 新增优化说明

## 本次新增优化

### ✅ 1. 仓位快照机制（定期同步）

**实现位置**：`data_server/binance/ws_binance/user_ws.py`

**功能**：
- 定期创建仓位快照，确保Redis记录与交易所一致
- 自动清理已平仓的仓位记录
- 确保所有真实仓位都在Redis集合中

**实现细节**：
1. 在`BinanceUserWS`类中添加`create_position_snapshot`方法
2. 添加`_snapshot_loop`后台任务，定期执行快照
3. 默认每5分钟执行一次（可配置）

**代码逻辑**：
```python
async def create_position_snapshot(self):
    # 1. 从Redis获取真实仓位（WebSocket已更新）
    real_positions = redis_sync.get_json("positions:binance")
    real_symbols = {p['symbol'] for p in real_positions if float(p.get('positionAmt', 0)) != 0}
    
    # 2. 从Redis获取记录的仓位
    recorded_symbols = redis_sync.conn.smembers("trading:open_positions:binance")
    
    # 3. 对比差异，清理已平仓的仓位
    for symbol in recorded_symbols:
        if symbol not in real_symbols:
            redis_sync.conn.srem("trading:open_positions:binance", symbol)
            logger.info(f"仓位快照：仓位已平仓，清理记录: {symbol}")
    
    # 4. 更新Redis集合
    for symbol in real_symbols:
        redis_sync.conn.sadd("trading:open_positions:binance", symbol)
```

**配置**：
- `snapshot_interval`: 快照间隔（秒），默认300秒（5分钟）

**触发时机**：
- 服务启动后自动开始
- 每5分钟执行一次
- 服务停止时自动停止

### ✅ 2. 实时仓位监控服务

**实现位置**：`agent_server/utils/position_monitor.py`

**功能**：
- 定期检查已开仓位的风险
- 监控仓位盈亏情况
- 识别需要止损/止盈的仓位
- 记录风险警告日志

**实现细节**：
1. `PositionMonitor`类：实时仓位监控服务
2. `check_all_positions`方法：检查所有仓位的风险
3. `handle_risk_positions`方法：处理有风险的仓位（可扩展为自动执行）
4. `monitor_loop`方法：监控循环任务

**风险检查规则**（借鉴NOFX）：
- 亏损超过10%：建议CLOSE（止损）
- 盈利超过20%：建议REDUCE（止盈）
- 其他情况：记录盈亏信息

**代码逻辑**：
```python
async def check_all_positions(self):
    # 1. 获取所有仓位
    all_positions = await self.position_builder.get_all_positions()
    
    # 2. 对每个仓位检查风险
    for position in all_positions:
        current_price = await get_mark_price_from_redis(exchange, symbol)
        needs_action, risk_desc, suggested_action = await self.risk_controller.check_position_risk(
            position, current_price
        )
        
        if needs_action:
            # 记录风险警告
            logger.warning(f"仓位风险警告: {symbol} | {risk_desc} | 建议: {suggested_action}")
```

**配置**：
- `check_interval`: 检查间隔（秒），默认60秒

**使用方式**：
```python
from agent_server.utils.position_monitor import PositionMonitor

# 创建监控服务
monitor = PositionMonitor(check_interval=60)

# 启动监控
await monitor.start()

# 停止监控
await monitor.stop()
```

**集成建议**：
可以在`agent_server/main.py`或启动脚本中启动监控服务：
```python
# 在main.py中
from agent_server.utils.position_monitor import get_position_monitor

async def main():
    # 启动仓位监控服务
    monitor = get_position_monitor(check_interval=60)
    await monitor.start()
    
    # 其他服务...
    
    # 停止时
    await monitor.stop()
```

import asyncio

async def main():

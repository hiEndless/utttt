## 使用说明

### 风控配置

可以在 `RiskController` 初始化时自定义配置：

```python
from agent_server.utils.risk_control import RiskController

# 自定义配置
config = {
    'max_positions': 3,              # 最大仓位数量
    'btc_eth_max_position_ratio': 5.0,  # BTC/ETH最大仓位比例
    'altcoin_max_position_ratio': 1.0,   # Altcoin最大仓位比例
    'min_position_size': 12.0,        # 最小仓位大小（USD）
    'max_margin_usage': 0.9,         # 最大保证金使用率
    'min_risk_reward_ratio': 3.0     # 最小风险回报比
}

risk_controller = RiskController(config)
```

### PositionBuilder使用

```python
from agent_server.utils.position_builder import PositionBuilder
from agent_server.utils.redis_client import RedisClient

# 初始化
position_builder = PositionBuilder(RedisClient())

# 处理交易
trade_data = {
    'order_type': 'open',
    'symbol': 'BTCUSDT',
    'position_side': 'LONG',
    'quantity': 0.01,
    'openAvgPx': 50000.0
}

await position_builder.process_trade(trade_data)

# 获取仓位
position = await position_builder.get_position('BTCUSDT', 'LONG')
```
